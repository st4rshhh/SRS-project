# Blood Donation Website – SRS

## 📌 Project Overview

The **Blood Donation Website** is a web-based platform designed to connect blood donors with patients, hospitals, and organizations that require blood.

## 📄 Documentation

The included PDF contains the **Software Requirements Specification (SRS)** for the project.

It covers:

* Project introduction and scope
* Functional and non-functional requirements
* User roles and use cases
* Hardware and software requirements
* Database requirements
* System flowchart
* Use-case diagram
* Database/ER diagram
* Future enhancements

## 👥 Main Users

* **Donors** – Register and respond to blood requests.
* **Recipients** – Create and track blood requests.
* **Hospitals** – Manage blood requirements.
* **Admin** – Manage users, requests, and system data.

## 🎯 Objective

To provide a simple and efficient platform for finding suitable blood donors and managing blood donation requests.
